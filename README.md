# web

Source for [physicalreasoning.ai](https://physicalreasoning.ai), built with [Astro](https://astro.build).

## Develop

Requires Node 22.23.4 or newer.

```sh
npm install
npm run dev       # local server at http://localhost:4321
npm run build     # static site in dist/
npm run preview   # serve dist/ locally
npm run check     # type-check
```

The build is fully static: `dist/` is plain HTML that any static host can serve.

## Layout

| Path | What it holds |
|---|---|
| `src/pages/` | One file per page; the file path is the URL (`start.astro` → `/start/`) |
| `src/layouts/Base.astro` | The document shell: meta, canonical and social tags |
| `src/layouts/BlogPost.astro` | Blog post shell: metadata and JSON-LD from `src/data/posts.ts` |
| `src/components/` | The `[Pr]` nav, the footer, JSON-LD |
| `src/data/posts.ts` | Blog posts, newest first; also drives `/blog/` |
| `src/data/roles.ts` | Open roles and their Tally forms; also drives `/join/` |
| `src/isotherm/` | The isotherm dashboard, imported from the isotherm repo (see below) |
| `scripts/` | Repo tooling |
| `public/` | Served as-is: `CNAME`, `robots.txt`, `sitemap.xml`, logo and social image |

Each page keeps its own stylesheet in a `<style is:global>` block.

The isotherm dashboard at `/isotherm/` is generated by `scripts/dashboard.py` in
[physicalreasoning/isotherm](https://github.com/physicalreasoning/isotherm). To update it, generate
the page there and import it:

```sh
npm run import:isotherm -- ../isotherm/path/to/index.html
```

This rewrites `src/isotherm/` (head tags, stylesheet, markup, chart code and data); don't edit
those files by hand.

To add a blog post, add an entry to `src/data/posts.ts` and a page at
`src/pages/blog/<slug>.astro` that wraps the article in `<BlogPost slug="<slug>">`. To add a
role, add an entry to `src/data/roles.ts`; give it a `listing` to show it on `/join/`. Add new
pages to `public/sitemap.xml`.
