isotherm API

Calibrated probabilities for tomorrow's high temperature in seven US cities, each answer read off one distribution that is scored every day against the market. Ask it, for example, for the chance New York reaches 76°F, as a plain API or as an MCP server an agent can call.

Open now

The public endpoint is free and needs no key. It runs on free hosting, so the first request after a quiet spell can take up to a minute.

curl -s -X POST https://isotherm.onrender.com/decide \
  -H 'content-type: application/json' \
  -d '{"city": "NY", "questions": [{"kind": "noul", "set": {"lo": 76}}]}'

Docs: isotherm.onrender.com/docs. MCP setup: docs/API.md. Results behind every number: the results page.
